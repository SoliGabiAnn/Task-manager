# Task Manager

## Tech Stack

The application is written in **Java 21.0.8**, and the visual aspects are built using the **JavaFX Maven plugin**.

---

## Description

This desktop app is designed to help you manage your responsibilities more effectively, thanks to a few helpful features.

---

### Projects, Tasks — Whatever You Wish

Users can create projects and tasks with a start date and a deadline.  
For tasks, an additional description field is available.  
This way, everything stays organized and easy to track.

---

### Separate Panes for Each Project Status

Based on the dates provided by the user, projects are sorted into two different panes:  
- **To Do**  
- **In Progress**

Once all task checkboxes are marked as complete, the project automatically moves to the **Done** pane.

---

### Deadline... Oh No!

To ensure that missed deadlines don’t go unnoticed, overdue projects and tasks will be **highlighted in red**.

---

### Progress at a Glance

Literally — with just one click, a **report** is generated summarizing:  
- Your activity  
- Completion times  
- Frequency of task creation
