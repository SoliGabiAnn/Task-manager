# Task manager
##Tech stack
Everything is written using Java 21.0.8 and visual aspects of application are done through Maven javafx plug-in

## Description 
This desktop app is created to help manage responsibilities better thanks to few helpful features.

### Project, Tasks , Whatever you wish
User can create projects and tasks with start date and deadline. In case of tasks also description field is added.
This way everything is in order and can be seen clearly.

### Separate panes for every status of project
Depending on the dates written by the user projects will be located in two different panes - "To Do" and "In progress". After all tasks chackboxes are marked project will be in pane "Done".

### Deadline...Oh no
To make sure that deadline passing will be noticed, the feature was added to light up given project or task red.

### Progress on the palm of your hand
Quite literally. By clicking just one button Raport is generated, that sums up your activity, time of completion or frequency of adding tasks.
